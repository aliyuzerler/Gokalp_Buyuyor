# Uygulama Öncesi Teknik Kontrol Listesi

- [ ] Node.js ve package manager sürümleri kaydedildi.
- [ ] Expo SDK uyumluluğu kontrol edildi.
- [ ] Expo development build akışı doğrulandı.
- [ ] Android SDK/JDK durumu kontrol edildi.
- [ ] iOS build için macOS/Xcode durumu not edildi.
- [ ] `expo-sqlite` standart SQLite olarak yapılandırıldı; SQLCipher yok.
- [ ] Dosya sistemi app-private path kullanıyor.
- [ ] Manuel unencrypted ZIP için dosya tabanlı/streaming arşiv stratejisi seçildi.
- [ ] Android SAF ve iOS Files export yaklaşımı doğrulandı.
- [ ] İnternet izni/network çağrısı gerektiren bağımlılıkların amacı kontrol edildi.
- [ ] Kişisel verilerin remote log/analytics'e gitmediği doğrulandı.
