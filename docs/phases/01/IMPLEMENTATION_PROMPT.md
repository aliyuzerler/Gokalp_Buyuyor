# Faz 01 — Tema, navigasyon ve onboarding

## Uygulama promptu

`docs/UI_UX.md` tasarım kurallarını uygula.

Yapılacaklar:
- Design token dosyası: renk, spacing, radius, typography, elevation.
- Yeniden kullanılabilir Button, Card, Input, EmptyState, SectionHeader, ScreenContainer bileşenleri.
- Expo Router alt navigasyon: Ana Sayfa, Günlük, Gelişim, Rehber, Arşiv.
- Her sekme için gerçek özellik henüz yoksa tasarım sistemini kullanan açıklayıcı placeholder ekran hazırla.
- İlk açılış onboarding akışı: Hoş geldin → Gökalp adı ve doğum tarihi → tamamlandı.
- Bu fazda profil kalıcı DB'ye yazılmayabilir; geçici onboarding akışı yeterli. Kalıcı kayıt Faz 2'de.
- Doğum tarihi seçimi gelecekteki tarihleri reddetsin; makul tarih aralığı validasyonu olsun.
- Ekranlar küçük telefonlarda, safe area ve klavye davranışında düzgün çalışsın.
- UI metinleri merkezi tr-TR kaynakta tutulsun.

Tema sıcak ve doğal olmalı; aşırı çocukça veya neon görünüm kullanma.

## Genel talimat

`AGENTS.md` kurallarına uy. Yalnızca bu fazı yap. Test edilmemiş davranışa tamamlandı deme. Faz raporunu oluştur ve dur.
