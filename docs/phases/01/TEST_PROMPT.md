# Faz 01 — Tema, navigasyon ve onboarding

## Test promptu

Faz uygulamasından sonra aşağıdaki senaryoları çalıştır. Eksik test yaz, testleri çalıştır ve başarısız olanları düzelt. Sonra kapsam dışına taşmadan faz raporuna test sonuçlarını ekle.

- [ ] 1. Beş alt sekme arasında geçiş yapılabiliyor.
- [ ] 2. Seçili sekme görsel olarak ayırt ediliyor.
- [ ] 3. Onboarding adımları tamamlanıyor ve hatalı tarih reddediliyor.
- [ ] 4. Kırık beyaz/toprak/adaçayı tasarım tokenları bileşenlerde kullanılıyor.
- [ ] 5. Klavye input alanlarını kapatmıyor.
- [ ] 6. Safe area Android ve iOS düzenleri kontrol edildi.
- [ ] 7. Ortak bileşen testleri eklendi.
- [ ] 8. Ekran görüntüsü veya kısa UI QA raporu eklendi.
