# Faz 00 — Repo ve Expo başlangıcı

## Uygulama promptu

Mevcut repo durumunu incele. Boşsa Expo Router ve TypeScript tabanlı yeni React Native projesi oluştur. Doluysa çalışan yapılandırmayı silmeden uyarlama planı çıkar ve güvenli biçimde gereken iskeleti ekle.

Yapılacaklar:
- Node/package manager/Expo SDK sürüm uyumluluğunu kontrol et.
- Expo Router ve TypeScript strict mode yapılandır.
- ESLint, Prettier, typecheck ve test komutları ekle.
- `src/` feature/domain/database/services/theme katmanlarını oluştur.
- Uygulama adını Gökalp Büyüyor, slug/scheme/bundle/package kimliğini `com.gokalp.buyuyor` olarak ayarla (platformun geçerli biçim koşullarını doğrula).
- Türkçe başlangıç ekranı ve basit uygulama shell'i göster.
- `.gitignore` içinde medya, yedek, build ve kişisel test verilerinin repoya girmesini engelle.
- `README.md`'ye gerçek kurulum ve çalıştırma adımlarını yaz.
- Paketleri Expo SDK uyumlu `npx expo install` ile kur.

Bu fazda DB, gerçek onboarding, günlük, rehber veya yedekleme özelliği geliştirme. Yalnızca sağlam iskelet oluştur.

`AGENTS.md` kurallarına uy. Yalnızca bu fazı yap. Test edilmemiş davranışa tamamlandı deme. Faz raporunu oluştur ve dur.
